Repère-marqueur

Commence par une photo de ta trousse

L'app lit le code de chaque marqueur sur ta photo. Ensuite, tu tapes un code et elle t'encercle le bon marqueur en rouge.

  1. Ouvre la trousse, capuchons vers toi.
  2. Place-toi au-dessus, pour voir toutes les étiquettes.
  3. Pas de flash : une lumière douce évite les reflets.

Ta photo reste sur cet appareil.

Toute la trousse

Dis-moi ce que tu veux dessiner ou quelle couleur tu veux fondre. Je choisis dans ta trousse et j'encercle en rouge les marqueurs à sortir.

Dessin joint à tes messages

Lire un code

Chaque code se lit en trois morceaux : la famille, la saturation, puis la luminosité.

Réussir un fade

  1. Même famille : garde les mêmes lettres (ex. que des B).
  2. Même saturation : garde le même premier chiffre. Ce sont les couleurs qui se fondent le mieux.
  3. Trois tons : un clair, un moyen, un foncé, en montant la luminosité de 2 à 4 à la fois.
  4. Du clair au foncé : pose le clair partout, ajoute le moyen dans les ombres, puis le foncé. Repasse le clair sur les jonctions pour fondre.

Fades possibles dans ta trousse

Les deux pointes

  • Pinceau : souple, pour ombrer, fondre et superposer.
  • Biseau : large, pour remplir une surface d'un trait régulier ; son arête fait aussi des lignes fines.
  • Blender 0 : sans couleur, il adoucit une jonction ou éclaircit une zone.

Anciens et nouveaux codes

Ohuhu a renuméroté ses marqueurs à alcool : les couleurs n'ont pas changé, seuls les codes ont changé. Sur leurs nuanciers, le gros code est le nouveau et le petit est l'ancien.
