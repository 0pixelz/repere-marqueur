Repère-marqueur

Commence par une photo de ta trousse

L'app lit le code de chaque marqueur sur ta photo. Ensuite, tu tapes un code et elle t'encercle le bon marqueur en rouge.

  1. Ouvre la trousse, capuchons vers toi.
  2. Place-toi au-dessus, pour voir toutes les étiquettes.
  3. Pas de flash : une lumière douce évite les reflets.
