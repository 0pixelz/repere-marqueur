      Un autre effet ?

      Lire un code

      Chaque code se lit en trois morceaux : la famille, la saturation, puis la luminosité.

      Réussir un fade

      1. Même famille : garde les mêmes lettres (ex. que des B).
      2. Même saturation : garde le même premier chiffre. Ce sont les couleurs qui se fondent le mieux.
      3. Trois tons : un clair, un moyen, un foncé, en montant la luminosité de 2 à 4 à la fois.
      4. Du clair au foncé : pose le clair partout, ajoute le moyen dans les ombres, puis le foncé. Repasse le clair sur les jonctions pour fondre.

      Les deux pointes

      • Pinceau : souple, pour ombrer, fondre et superposer.
      • Biseau : large, pour remplir une surface d'un trait régulier ; son arête fait aussi des lignes fines.
      • Blender 0 : sans couleur, il adoucit une jonction ou éclaircit une zone.
